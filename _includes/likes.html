{%- comment -%} likes.html — the "liked this?" control at the end of a post. PROGRESSIVE ENHANCEMENT, AND THE REASON IT MATTERS HERE. The whole block ships `hidden` and is revealed only after the API answers. So with JavaScript off, or the Worker not deployed, or the API unreachable, a reader sees exactly the page they see today — never a dead button or a spinner that spins forever. That is also what makes this safe to commit before the Worker exists, which is the staged rollout: ship the inert half, confirm it is inert, then turn the backend on. ZERO PERSONAL DATA, BY DESIGN. Dedup is `localStorage` only. No cookie, no IP hash, no fingerprint, nothing stored about who clicked — so this needs no consent banner and there is no reader data to leak, which is the whole point of not using Disqus. The cost is honest: a determined person can clear storage and like again. For a family blog that is the right trade; the counter is warmth, not an election. Same-origin fetch to /api/likes/ — see workers/likes/src/worker.js for why it is on this domain and not a *.workers.dev hostname. {%- endcomment -%}
